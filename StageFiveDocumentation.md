Results summary:

MVP core functionalities
The primary system workflow from the front-end till the back-end system. Handled possible logical errors by user input using a validation system.

Outcome VS Initial Objectives
Most of the wanted features were successfully implemented, but unfortunately few were deferred to future iterations. Although, core objectives like the main functionality and the smooth front-end look were handled.

performance indicators
MVP finished within the timeframe. Testing was successful.

Lessons learned:

What went well and why?
we had focused more when we did the technical documentation due to its detailed questions. Team meetings helped us reduce misunderstandings.

Challenges and how they were handled
Time stress -> handled by only focusing on main features. Technical/Coding difficulties -> research and debugging as well as team collaborative aid. Testing limitations -> focused on testing the main features first.

How our team can improve for future projects
Give more time for testing. Try to have team meetings very often.


What worked well as a team
conducting multiple team meetings. commitment to this project. flexibility within the team.
